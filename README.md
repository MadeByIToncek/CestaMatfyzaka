## Inicializace
Nejdříve pomocí následujícího příkazu vygenertujte prázdné schéma soutěže:

> Tento příkaz nahradí stávající schéma, pokud v repozitáři nějaké již existuje!
```sh
dotnet run --project ./scripts -- -e > schema.json
```
